Toys API Documentation

Toys API

HTTP Method Route Description Parameters / Request Body
GET /toys Returns all toys from the database. Returns 10 toys per page. skip (optional): Page number, starting from 0.

Example:
/toys?skip=0
/toys?skip=1
GET /toys/search Search toys by name or info.
Search is case-insensitive.
Returns up to 10 toys per page. 		s (required): Search text.
skip (optional): Page number.

Example:
/toys/search?s=lego&skip=0
GET /toys/category/:catname Returns toys from a specific category.
Category name must match the stored category.
Supports pagination. 		catname (required): Category name.
skip (optional): Page number.

Example:
/toys/category/Lego?skip=0
GET /toys/prices Returns toys within a specified price range.
Returns up to 10 toys per page. 		min (optional): Minimum price.
max (optional): Maximum price.
skip (optional): Page number.

Example:
/toys/prices?min=50&max=200&skip=0
GET /toys/count Returns the total number of toys in the database. No body.

Example response:
{"count":12}
GET /toys/single/:id Returns a single toy by its MongoDB ID. id (required): Toy ID.

No body.
POST /toys Creates a new toy in the database.
The toy belongs to the authenticated user.

JWT required. 		JSON toy object.
user_id is assigned automatically.

Requires:
x-api-key
PUT /toys/:id Updates an existing toy.
Users can update only their own toys.

JWT required. 		id: Toy ID.
JSON toy object.

Requires:
x-api-key
DELETE /toys/:id Deletes a toy from the database.
Users can delete only their own toys.

JWT required. 		id: Toy ID.

No body.

Requires:
x-api-key

Users API

HTTP Method Route Description Request Body
POST /users Registers a new user.
Password is stored as a bcrypt hash. 		JSON object containing:
name
email
password
POST /users/login Authenticates a user.
Returns a JWT token after successful login. 		JSON object containing:
email
password

Toy Request Body

Use this JSON for:
POST /toys
PUT /toys/:id 

{
  "name": "Lego Car",
  "info": "Lego racing car",
  "category": "Lego",
  "img_url": "",
  "price": 150
}

name, info and category: 2–99 characters.
price: 1–999.
img_url: Optional, up to 200 characters.

User Request Bodies

Register: POST /users 

{
  "name": "Example User",
  "email": "user@example.com",
  "password": "examplePassword123"
}

Login: POST /users/login 

{
  "email": "user@example.com",
  "password": "examplePassword123"
}

Authentication & Permissions

Login using POST /users/login.
After successful login, the server returns a JWT token.
The token must be included in the request headers when adding, updating or deleting toys. 

x-api-key: YOUR_JWT_TOKEN
Action Visitor Authenticated User
View toys Yes Yes
Search toys Yes Yes
Add a toy No Yes
Edit a toy No Own toys only
Delete a toy No Own toys only
