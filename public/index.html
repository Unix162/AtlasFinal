Toys API Documentation

API reference for toys, users, pagination and authentication.

Getting started

API Base URL: https://atlas-final-tau.vercel.app

Responses are returned as JSON. Requests with a JSON body should include Content-Type: application/json.

For protected routes, log in first and send the received JWT token in the x-api-key request header.

Toys API

HTTP Method Route Description Parameters / Request Body
GET /toys Returns all toys, 10 per page. skip (optional): zero-based page number; default 0.
/toys?skip=1 returns the second page.
GET /toys/search Searches toy name or info (case-insensitive). Returns up to 10 results per page. s (required): search text.
skip (optional): page number.
Example: /toys/search?s=lego&skip=0
GET /toys/category/:catname Returns toys in the specified category (exact match), up to 10 per page. catname (required): category name.
skip (optional): page number.
Example: /toys/category/Lego?skip=0
GET /toys/prices Returns toys within a price range, up to 10 per page. min (optional): minimum price.
max (optional): maximum price.
skip (optional): page number.
Example: /toys/prices?min=50&max=200&skip=0
GET /toys/count Returns the total number of toys. No body.
Example response: {"count":12}
GET /toys/single/:id Returns one toy by its MongoDB ID. id (required): toy ID.
No body.
POST /toys Creates a toy for the authenticated user.
JWT required. 		JSON toy object (example below). user_id is assigned automatically.
PUT /toys/:id Updates a toy owned by the authenticated user.
JWT required. 		id: toy ID.
JSON toy object (example below).
DELETE /toys/:id Deletes a toy owned by the authenticated user.
JWT required. 		id: toy ID.
No body.

Users API

HTTP Method Route Description Request Body
POST /users Registers a new user. Password is stored as a bcrypt hash. name, email, password (JSON).
POST /users/login Authenticates a user and returns a JWT token. email, password (JSON).

Toy request body

Use this JSON for POST /toys and PUT /toys/:id. 

{
  "name": "Lego Car",
  "info": "Lego racing car",
  "category": "Lego",
  "img_url": "",
  "price": 150
}

name, info and category: 2–99 characters. price: 1–999. img_url: optional, up to 200 characters.

User request bodies

Register: POST /users 

{
  "name": "Example User",
  "email": "user@example.com",
  "password": "examplePassword123"
}

Login: POST /users/login 

{
  "email": "user@example.com",
  "password": "examplePassword123"
}

Authentication & permissions

Log in with POST /users/login, copy the returned JWT token, and include this header when adding, editing or deleting toys: 

x-api-key: YOUR_JWT_TOKEN
Action Visitor Authenticated user
View and search toys Yes Yes
Add a toy No Yes
Edit a toy No Own toys only
Delete a toy No Own toys only

This project does not implement a separate administrator role.
